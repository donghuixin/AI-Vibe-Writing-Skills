# Defensive Writing

Read [SKILL.md](../../SKILL.md) for scope and workspace conventions, then use [14 · Defensive Writing](../../.ai_context/prompts/14_defensive_writing_agent.md). The prompt defines the evidence checks and repair choices; this workflow adds no strategy order or separate review checklist.

Read the specified manuscript section and relevant project evidence. Reuse existing C/E/B links if available; missing facts stay explicit. Return located risks and evidence-supported edits within the requested scope.

If the task is a formal reply to actual reviewer comments, start with [16 · Response Letter](../../.ai_context/prompts/16_response_letter_agent.md) and consult 14 only where needed. A request to fix grammar does not activate a risk audit.
