# Response Letter

Read [SKILL.md](../../SKILL.md) for scope and workspace conventions, then use [16 · Response Letter](../../.ai_context/prompts/16_response_letter_agent.md) as the primary prompt.

Work from the supplied decision letter, reviewer comments, original response, relevant manuscript version, and available evidence. Preserve the actual requests and their strength. Use the author's voice for reply text and keep pending checks separate from completed changes.

Call systems logic or defensive review only for specific questions that need those checks. Missing data do not justify invented results or automatic new experiments. Continue the authorized drafting or revision without an additional blanket approval step, and report the exact unresolved items.
