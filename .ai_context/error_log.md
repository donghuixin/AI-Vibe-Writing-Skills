# Author Corrections

这是空白模板，不是作者的历史错误记录。旧版内置的通用建议见 [写作建议](../docs/writing-guidelines.md)，不自动成为个人禁词表。

在论文工作区记录作者实际提出的纠正：

- **Date / Task / Source**:
- **Original Wording / Author's Correction**:
- **Reason**: technical_error / grammar / local_style / confirmed_preference
- **Scope**: 当前句、章节、文体或明确的跨项目偏好
- **Future Guidance / Exceptions / Superseded By**:

一次改词不自动成为永久规则。不要将正确的技术词、必要转折或已成立的证明措辞判为错误，也不要为消除模板感改变术语、公式和证据强度。
