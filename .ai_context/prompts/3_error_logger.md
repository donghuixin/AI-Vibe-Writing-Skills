# Author Correction Logger

将作者的实际纠正保存为可回溯的编辑经验，并修改本次受影响的文字。

1. 找到原句和任务，分清事实错误、语法问题、当前句的选择及明确的长期偏好。
2. 在论文工作区的 `error_log.md` 记录原句、改句、来源、原因、适用范围与例外。一次纠正默认只作用于当前语境；作者明确推广或多处样本支持时再扩大范围。
3. 按 [5_long_term_memory.md](5_long_term_memory.md) 更新相关记忆，不将局部建议提升为永久禁词。
4. 完成本次已授权修改。未要求修改其他章节时，不顺带扩写全文。

输出实际改句及新增记录。没有作者纠正的证据时，不创建带虚构日期的“历史错误”。
